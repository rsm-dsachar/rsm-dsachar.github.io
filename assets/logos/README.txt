Put the three company logos in this folder with these exact file names:

  thermo-fisher.png
  bank-of-america.png
  ericsson.png

Until a file is here, the site shows a lettered badge (T, B, E) for that company.
Evalueserve has no logo slot and always shows its "E" badge.
Each logo is shown on a white tile, so a PNG with a transparent or white background works best.
If you only have an SVG, change ".png" to ".svg" for that company in index.html.
